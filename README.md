# Bi-Weekly Management Update

A dependency-free, manager-facing archive for ongoing bi-weekly project updates.

## Use it locally

Open `index.html` in a browser. Use **New update** to add an edition or **Edit this update** to revise the current one. Updates created in the editor are stored in that browser only. Use the download icon to export a JSON backup before moving to another device.

## Share it by email

Host this folder with GitHub Pages:

1. Create a GitHub repository named `biweekly_management_update` and push these files to its `main` branch.
2. In the repository, choose **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, then select `main` and `/(root)`.
4. GitHub will display the public Pages URL. Copy it with the link icon from the site, then email that URL to your manager.

For a company-private update, publish it in the organization’s approved internal site or repository visibility tier. Do not put confidential task details on a public Pages site.
